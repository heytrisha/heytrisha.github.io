Evently

An event discovery platform designed to make finding and hosting experiences more joyful, personalized, and efficient.

Web App Mobile App Discovery Product Design

“Evently turns overwhelming event listings into a personal, joyful discovery experience for the people attending and the people hosting.”

  • Personalized Discovery

    Smart recommendations and intuitive filters that surface events worth attending.

  • Two-sided Platform

    Designed for Explorers seeking inspiration and Creators seeking visibility.

  • Emotionally Engaging

    An experience that feels creative and lively, not transactional.

The Problem

Event discovery is broken, for both sides.

Event platforms today feel like endless catalogues. For Explorers, it’s decision fatigue: hundreds of listings, no personalization, and no way to interact with hosts before committing. For Creators, it’s invisibility: even great events struggle to be seen, forcing them to promote on social media instead of using built-in tools.

Listings, zero relevance

Most platforms surface every event equally, leaving users to do the filtering themselves.

Filters, still no match

Date, location, price. Niche interests are still buried under generic categories.

Abandoned searches

Users drop off when overwhelmed by options and lack of guidance.

Promotion scattered across channels

Hosts juggle Instagram, email, and DMs because the platform gives them no built-in reach.

The Solution

Evently is event discovery designed for the person, not the listing.

Six design choices, each tied to a real problem Explorers and Hosts face.

01

Personalized Discovery

Smart recommendations that surface events worth attending.

02

Faster Search

03

Smarter Filtering

04

05

Explorers and hosts can connect before committing.

06

Creative, Lively UI

An interface that feels like the events it surfaces.

The thinking

Both sides feel the same kind of invisible.

The problem with event platforms isn’t the listings. It’s that the listings are presented with equal weight to a sold-out warehouse show and a yoga class in someone’s garage, with no signal to the user about which is which and no signal to the host about whether their event reached anyone. Both sides feel the same kind of invisible.

Evently’s six design choices are a thesis that discovery should be designed for the two humans at each end of the listing: the person deciding whether tonight is worth going out, and the person wondering if anyone noticed their event. Build around that, and the catalogue becomes a side effect.
